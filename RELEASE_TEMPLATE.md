# 📦 Annotation Tool v2.0.0

This release includes builds for **macOS**, **Windows**, and **Linux**. The Annotation Tool allows intuitive annotation of prose or poetry collections in standalone desktop environments.

---

## ✅ What's New

- 🖥️ Native installers for macOS, Windows, and Linux (.dmg, .exe, .deb, .AppImage)
- 🎨 Improved interface for volume-level metadata and progress tracking
- 🧠 Dynamic label creation per annotation category
- 🗂️ Volume notes with persistent save/load functionality
- 🪟 Settings refactor: session types, file paths, label structures

---

## 📥 Download

| Platform | Installer | Notes |
|----------|-----------|-------|
| macOS    | [`AnnotationTool.dmg`](./AnnotationTool.dmg) | For macOS 10.12+ |
| Windows  | [`AnnotationTool.exe`](./AnnotationTool.exe) | Standard NSIS installer |
| Linux    | [`AnnotationTool.deb`](./AnnotationTool.deb) | For Debian/Ubuntu |
| Linux    | [`AnnotationTool.AppImage`](./AnnotationTool.AppImage) | Portable executable |

---

## ⚙️ How to Use

1. Download the file appropriate for your operating system.
2. Run the installer or launch the `.AppImage` directly (after `chmod +x` if needed).
3. Start annotating!
